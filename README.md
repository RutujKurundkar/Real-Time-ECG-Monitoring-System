# Real-Time ECG Monitoring System

## Overview
The Real-Time ECG Monitoring System is designed to acquire and visualize the electrical activity of the human heart using the AD8232 ECG sensor module and an ESP8266 microcontroller. The system captures ECG signals through medical electrodes attached to the body and displays the waveform in real time using the Arduino IDE Serial Plotter.

This project demonstrates biomedical signal acquisition, signal conditioning, and real-time waveform monitoring using embedded systems. It helps in understanding core ECG waveform components such as the P wave, Q wave, R wave, and S wave.

## Working Principle
1. **Detection:** Three Ag/AgCl electrodes attached to the body detect minor skin-surface electrical potentials generated by heart muscles.
2. **Conditioning:** The AD8232 module filters out muscle noise (EMG) and amplifies the weak cardiac microvolt signals.
3. **Sampling:** The ESP8266 development board reads the processed, continuous analog waveform using its onboard Analog-to-Digital Converter (A0 ADC pin).
4. **Streaming:** Data packets are streamed sequentially through the serial bus port to a host machine.
5. **Visualization:** The Arduino IDE Serial Plotter converts string inputs into visual waveforms instantly.

## 🔌 Hardware Connection Guide
To replicate this setup, connect the AD8232 ECG sensor module to the ESP8266 microcontroller according to the pin configuration map below.


| AD8232 Pin | ESP8266 Pin | Pin Function | Description |
| :--- | :--- | :--- | :--- |
| **GND** | GND | Ground | Power ground connection |
| **3.3V** | 3V3 | Power | 3.3V power supply input |
| **OUTPUT** | A0 | Analog Output | Raw analog ECG signal output |
| **LO-** | D5 (GPIO14) | Digital Input | Lead-Off Detect Minus |
| **LO+** | D6 (GPIO12) | Digital Input | Lead-Off Detect Plus |

### 🛑 Important Wiring Notes
* **Power Source:** Always power the AD8232 module using the **3.3V pin** on the ESP8266. Connecting it to a 5V rail can permanently fry the sensor IC.
* **Lead-Off Detection:** The LO- and LO+ pins trace physical continuity to verify that electrodes remain securely stuck to the subject's skin.

## Installation and Setup

```bash
# Clone the repository
git clone https://github.com/RutujKurundkar/Real-Time-ECG-Monitoring-System.git

# Enter the project directory
cd Real-Time-ECG-Monitoring-System
```

### Execution Steps
1. Wire the AD8232 module to the ESP8266 development board using the connection map.
2. Snap the electrode cables onto the three Ag/AgCl disposable skin patches and place them properly on the body.
3. Open the main program file inside the `software/` folder using the Arduino IDE.
4. Select the correct ESP8266 Board target and COM port inside your IDE settings.
5. Compile and upload the codebase.
6. Open the **Serial Plotter** application window (`Ctrl + Shift + L`) configured to match your software baud rate to view incoming signals.
