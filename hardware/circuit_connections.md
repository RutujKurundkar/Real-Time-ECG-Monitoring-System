# Hardware Connection Guide

| AD8232 Pin | ESP8266 Pin | Function |
|---|---|---|
| GND | GND | Ground Connection |
| 3.3V | 3V3 | Power Supply |
| OUTPUT | A0 | Analog ECG Signal Output |
| LO+ | D6 | Lead-Off Detection |
| LO- | D5 | Lead-Off Detection |

## Notes

- Ensure proper electrode placement before powering the system.
- Use only 3.3V supply for the AD8232 module.
- Loose electrodes may introduce noise in the ECG waveform.
